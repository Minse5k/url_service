# 03: 단축 코드 충돌 시 재시도

**What to build:** 새로 만든 단축 코드가 이미 다른 링크에 쓰이고 있으면, 링크 생성이 실패하지 않고 새 단축 코드로 다시 시도해 링크를 만든다.

**Blocked by:** 02

**Status:** done

- [x] 단축 코드가 이미 존재하면 새 코드를 생성해 재시도한다
- [x] 재시도는 횟수 상한이 있고, 상한을 넘으면 링크 생성은 오류를 돌려준다
- [x] 기존 링크는 덮어쓰이지 않는다
- [x] 같은 코드를 의도적으로 먼저 내는 생성기를 주입한 seam 테스트로, 충돌 후 다른 단축 코드로 링크가 만들어지는 것을 검증한다
