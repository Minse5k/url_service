# 02: 링크 생성과 단축 URL 표시

**What to build:** 사용자가 원본 URL을 입력하고 "생성"을 누르면 새 링크가 저장되고, 화면에 단축 URL과 원본 URL이 함께 표시된다. 같은 원본 URL을 다시 입력해도 매번 새 링크(새 단축 코드)가 만들어진다. 원본 URL 검증은 하지 않는다.

구성:
- `core`에 링크 생성 서비스: 원본 URL을 받아 단축 URL을 돌려준다. 단축 코드 생성기와 저장소(trait)를 주입받는다.
- 단축 코드: 무작위 base62 7자.
- 단축 URL: `BASE_URL` + `/` + 단축 코드. `BASE_URL`은 환경 변수로 받고 기본값은 `http://localhost:8080`.
- `storage`에 SQLite(`sqlx`) 저장소 구현. 링크는 단축 코드(유일)와 원본 URL을 가진다.
- `web`의 server function은 서비스를 호출만 하는 얇은 어댑터.
