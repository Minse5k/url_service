# 04: 단축 URL 복사

**What to build:** 링크 생성 결과 옆의 "복사" 버튼을 누르면 단축 URL이 클립보드에 복사되고, 버튼이 2초 동안 "복사됨"으로 바뀐 뒤 다시 "복사"로 돌아온다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 단축 URL이 표시될 때 "복사" 버튼이 함께 보인다
- [ ] 버튼을 누르면 단축 URL 전체가 클립보드에 복사된다
- [ ] 누른 직후 2초 동안 "복사됨"이 표시되고 이후 "복사"로 돌아온다
- [ ] 브라우저에서 직접 눌러 붙여넣기로 확인한다(자동 UI 테스트는 범위 밖)
