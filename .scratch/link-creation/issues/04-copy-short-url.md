# 04: 단축 URL 복사

**What to build:** 링크 생성 결과 옆의 "복사" 버튼을 누르면 단축 URL이 클립보드에 복사되고, 버튼이 2초 동안 "복사됨"으로 바뀐 뒤 다시 "복사"로 돌아온다.

**Blocked by:** 02

**Status:** ready-for-human

- [x] 단축 URL이 표시될 때 "복사" 버튼이 함께 보인다
- [ ] 버튼을 누르면 단축 URL 전체가 클립보드에 복사된다
- [x] 누른 직후 2초 동안 "복사됨"이 표시되고 이후 "복사"로 돌아온다
- [ ] 브라우저에서 직접 눌러 붙여넣기로 확인한다(자동 UI 테스트는 범위 밖)

**검증 메모 (agent):** 브라우저(dx serve)에서 버튼 표시, `navigator.clipboard.writeText`에 단축 URL 전체가 넘어가는 것, "복사됨" 2초 후 "복사" 복귀, 2초 안에 다시 누르면 타이머가 새로 시작되는 것을 확인했다. 에이전트 브라우저가 클립보드 쓰기 권한을 거부해서 실제 클립보드 내용과 붙여넣기는 확인하지 못했다. 사람이 직접 눌러 붙여넣기로 확인한 뒤 나머지 두 항목을 체크한다.
